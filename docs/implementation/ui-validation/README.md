## Reading the differences
The residual differences are not structural. They come from:
* **Data vs mock.** The reference shows mock counters (`120` books, `4500` views, `0.00` prices); the new pages show database values (29 demo books, real demo prices). Statistics and price text therefore differ by design.
* **Missing uploads.** No logo/poster/social links exist in settings (the originals were DB uploads that were not recovered), so the poster band and social icons are absent unless an admin uploads them; covers fall back to the legacy default cover instead of the reference's grey placeholder.
* **Result counts.** `/search` renders real matching rows (a different number of cards than the reference's 8 mock cards), hence the larger vertical diff.
* **Header CMS links.** Header/footer links come from the `pages` table (demo pages) rather than fixed mock links.
* **Mobile (390 px).** Larger percentages mostly reflect vertical shifts accumulated from the above on long pages.

## Not verified
* No comparison with real screenshots of the original website (owner to supply them; `docs/legacy-ui/14-ui-acceptance-checklist.md` remains the sign-off).
* The weak tablet header (9 px links at 768 px) is legacy behaviour and was **kept** (conscious fidelity choice, `docs/legacy-ui/13` §7).
* Accessibility was checked structurally (labels, `role`, `aria-label`s, keyboard-reachable controls by construction); no automated axe/Lighthouse run was performed.
